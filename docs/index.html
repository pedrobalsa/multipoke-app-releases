O Windows pode mostrar um aviso na primeira instalação

O instalador ainda não tem certificado de assinatura digital. Por isso, o SmartScreen pode mostrar “O Windows protegeu o computador” ou “Fornecedor desconhecido”. O aviso de aplicativo não reconhecido, por si só, não é uma detecção de vírus.

Se aparecer essa tela, confira que o arquivo veio do botão de download desta página. No SmartScreen, escolha Mais informações → Executar assim mesmo para continuar. Não precisa desativar o antivírus.

Se houver uma detecção de ameaça ou outro bloqueio, envie uma captura no canal do app no Discord para verificarmos.

Antes da próxima hunt

Como recebo as próximas atualizações?

O cliente avisa quando há uma versão nova. Clique em Atualizar para baixar e depois em Reiniciar e instalar. Você não precisa baixar outro instalador por aqui a cada versão.

As atualizações do jogo chegam normalmente, separadas das atualizações do aplicativo.

Como conferir a integridade do download?

Os arquivos oficiais são hospedados no GitHub Releases. Se quiser conferir se o instalador baixado é idêntico ao publicado, compare seu hash SHA-256 com o arquivo de verificação da mesma versão.

Posso continuar jogando no navegador?
