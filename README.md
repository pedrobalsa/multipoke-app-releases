# MultiPoke App

Distribuição oficial do cliente MultiPoke App para Windows x64.

[Baixar a versão mais recente](https://github.com/pedrobalsa/multipoke-app-releases/releases/latest)

O cliente reúne os seis treinadores da sua conta do [MultiPoke Idle](https://multipoke.io), com grupos, Poképedia e divisões de painéis.

A partir da v0.1.16, o aplicativo instalado avisa quando há atualização. Você escolhe baixar e depois reiniciar para instalar. Quem está na v0.1.15 ou anterior precisa instalar a primeira versão com esse recurso manualmente.

Este repositório contém apenas documentação de distribuição e releases com instaladores, blockmaps, latest.yml e checksums. As versões do cliente são publicadas separadamente das atualizações do jogo. O código do projeto permanece privado.
