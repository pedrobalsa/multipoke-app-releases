# MultiPoke App

Distribuição oficial do cliente MultiPoke App para Windows 64 bits.

**[Baixar o MultiPoke App](https://pedrobalsa.github.io/multipoke-app-releases/)**

A página de download apresenta o instalador atual, instruções de instalação e login, informações sobre o aviso do Windows e a verificação opcional por SHA-256. O botão baixa o instalador diretamente.

O cliente reúne até seis treinadores da sua conta do [MultiPoke Idle](https://multipoke.io), com grupos, Poképedia, indicadores e divisões de painéis.

A partir da v0.1.16, o aplicativo instalado avisa quando há atualização. Você escolhe baixar e depois reiniciar para instalar. Quem está na v0.1.15 ou anterior precisa instalar a primeira versão com esse recurso manualmente.

As [releases](https://github.com/pedrobalsa/multipoke-app-releases/releases) hospedam instaladores Windows, arquivos de atualização e checksums. As versões do cliente são publicadas separadamente das atualizações do jogo.

O site está em `docs/`, publicado pelo GitHub Pages a partir da pasta `docs` da branch `main`. Ele consulta a última release pública para manter o download atualizado; quando a consulta falha, preserva um link direto para a versão de referência identificada na página.
